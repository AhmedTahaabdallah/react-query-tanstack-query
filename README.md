# React Query / TanStack Query Playground

![React](https://img.shields.io/badge/React-19-blue)
![TanStack Query](https://img.shields.io/badge/TanStack%20Query-Latest-red)

A practical repository for learning and experimenting with React Query (TanStack Query) through real-world examples and reusable patterns.

The goal of this repository is to explore modern server state management techniques in React applications while applying best practices and scalable architecture.

## Topics Covered

### ✅ Fundamentals
- QueryClient & QueryClientProvider
- Creating Queries with `useQuery`
- Loading & Error States
- React Query DevTools
- Query Keys
- Caching
- Stale Time & Cache Time
- Parallel Queries
- Dependent Queries
- Dynamic Queries
- Prefetching
- Mutations
- Pagination

### 🚧 Coming Soon
- Query Invalidation
- Optimistic Updates
- Infinite Queries
- Custom Query Hooks
- Best Practices
- Performance Optimizations

## Tech Stack

- React
- TanStack Query (React Query)
- Axios
- JavaScript

## Project Goals

This repository is intended to:

- Learn React Query from fundamentals to advanced concepts.
- Build reusable API-layer patterns.
- Explore server state management best practices.
- Keep API logic clean and maintainable.
- Share practical examples with the developer community.

More examples and improvements will be added as I continue learning.
